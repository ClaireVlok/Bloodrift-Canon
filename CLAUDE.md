# Bloodrift Canon: Instructions for Claude

This repository is the single source of truth for continuity across The Bloodrift Trilogy (Moonfall, Eternal Night, Blood Reckoning). Each revision session attaches this repository plus the repository of the book being revised.

## At the Start of Every Session

1. Read `series-canon.md`, `reserved-names.md`, `decision-log.md` and the canon file for the book being revised (for example `moonfall.md`).
2. Read the book repository's `reports/findings-tracker.csv` to see which findings are still open.

## During the Session

- Never change a fact marked LOCKED without Claire's explicit instruction.
- When Claire makes a decision, record it in `decision-log.md` (moving it from Open to Confirmed) and update the canon files in the same change.
- Before naming any character, check `reserved-names.md` and search all three manuscripts.
- Do not assume the Series Bible is right when it conflicts with a manuscript. Log the conflict and ask.
- Save changes with a note naming the book, the phase and the decision or finding IDs, for example "MF Phase 1: BIB-001 to BIB-003".

## Writing Conventions

- UK English.
- No em dashes or en dashes, in manuscripts or in anything written for Claire. In manuscripts, interrupted speech uses an ellipsis.
- Headings in title case.
